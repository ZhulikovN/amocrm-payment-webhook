Инструкция по работе с интеграцией amoCRM → Платформа



Как работает интеграция

При выставлении счета в amoCRM и его оплате, данные автоматически отправляются на платформу для создания доступа к курсам.

**Важно:** Для корректной работы интеграции необходимо правильно заполнить поля в сделке и счете.

1. Заполнение контакта

### Обязательные поля контакта:

- **Имя и Фамилия** - ФИО клиента (например: Иван Иванов)
- **Email раб.** - рабочий email клиента 
- **Раб. тел** - рабочий телефон клиента

Эти поля контакта ОБЯЗАТЕЛЬНО должны быть заполнены.  
2. Заполнение сделки

### Обязательные поля сделки:

#### **Класс ученика**

Поле: `wordpress_class` (в разделе "Техническая информация")

Заполнить класс ученика: 7, 8, 9, 10 или 11

#### **Тариф**

Поле: `Какой курс куплен`

Выбрать один из тарифов:

- **Стандарт**
- **ПРО**
- **Самостоятельный**
- **Базовый**

**Важно:** Платформа поддерживает только эти 3 тарифа для "Весенний курс 2к26" (Стандарт/ПРО/Самостоятельный).

**Важно:** Платформа поддерживает только эти 3 тарифа для "Марафон 2к26"(Стандарт/ПРО/Базовый).

**Важно:** Платформа поддерживает только эти 1 тариф для "Годовой 2к27 ЕГЭ 10/11 класс" (Стандар).



#### **Предметы**

Поле: `Какой предмет выбрал`

Выбрать предметы которые покупает клиент (можно несколько).

**Важно:** Количество предметов в этом поле должно совпадать с количеством позиций в счете.

Эти поля сделки ОБЯЗАТЕЛЬНО должны быть заполнены.  
3. Создание счета

### Обязательные действия:

#### **1. Ссылка на сделку**

В поле **"Описание"** при создании счета ОБЯЗАТЕЛЬНО указать ссылку на сделку:

```
https://egeland.amocrm.ru/leads/detail/40095211
```

Без этой ссылки интеграция не сможет получить данные о клиенте и курсах.

#### **2. Позиции счета**

Для каждого предмета создать отдельную позицию:

**Название** - указать название курса из списка поддерживаемых (см. ниже)

Например:

- `Весенний курс 2к26 ЕГЭ 11 класс` - для Русского языка
- `Весенний курс 2к26 ЕГЭ 11 класс` - для Биологии

**Цена** - стоимость курса за 1 месяц (например: 3000)

**Количество** - количество месяцев (например: 1)

#### **3. Оплата счета**

После оплаты счета клиентом и изменение статус на **"Оплачен"**.

Интеграция автоматически отправит данные на платформу.

4. Как проверить результат отправки на платформу

После изменения статуса счета на “Оплачен” интеграция автоматически добавляет примечание в сделку amoCRM.
Если отправка прошла успешно
В сделке появится примечание примерно такого вида:

Данные успешно отправлены на платформу
Время: 2026-04-08 17:30:47
Статус: 200 OK
Клиент получит доступ к курсам на платформе.



Это означает, что данные успешно переданы на платформу.
Если при отправке возникла ошибка
В сделке появится примечание с текстом ошибки и рекомендациями, например:

Ошибка отправки на платформу
Время: 2026-04-08 17:31:26
Статус: 500
Ответ платформы: Внутренняя ошибка платформы

Возможные причины:
- Неправильно заполнены поля в сделке (класс, тариф, предметы)
- Неправильно заполнены поля в контакте (email, телефон)
- Неправильно заполнен счет (ссылка на сделку, названия курсов)
- Технический сбой на платформе

Действия:
1. Проверить все обязательные поля в сделке и контакте
2. Проверить что в счете указана правильная ссылка на сделку
3. Повторно изменить статус счета на "Оплачен"
4. Если ошибка повторяется - обратиться в техподдержку



Что делать при ошибке
Проверить обязательные поля в контакте и сделке


Проверить, что в счете указана правильная ссылка на сделку


Проверить, что названия курсов в счете заполнены корректно


Повторно изменить статус счета на “Оплачен”


Если ошибка повторяется - обратиться в техподдержку


Важно: примечание в сделке - это основной способ понять, успешно ли данные ушли на платформу.

Важно:
При добавлении новых курсов или изменении названий существующих курсов и тарифов необходимо заранее передать новый список названий, чтобы мы добавили их в интеграцию. 
Если курс будет передан с названием, которого нет в списке поддерживаемых, интеграция не сможет корректно обработать заказ.


6. Что отправляется на платформу

Интеграция автоматически формирует данные для платформы:

### Название курса с тарифом

Для **"Весенний курс 2к26"** к названию автоматически добавляется выбранный тариф:

- `Весенний курс 2к26 11 класс` + тариф "Стандарт" → `Весенний курс 2к26 11 класс Standart`
- `Весенний курс 2к26 10 класс` + тариф "ПРО" → `Весенний курс 2к26 10 класс PRO`
- `Весенний курс 2к26 9 класс` + тариф "Самостоятельный" → `Весенний курс 2к26 9 класс Самостоятельный`

7. Пример заполнения

### Сценарий

Клиент Иван Иванов (11 класс) купил Весенний курс на 2 предмета (Русский и Биология) по тарифу "Стандарт" на 1 месяц.
Цена каждого предмета 3000 руб.

### Шаги:

**1. Контакт:**

- Имя: `Иван Иванов`
- Email раб.: `ivan@example.com`
- Раб. тел: `+7 900 123-45-67`

**2. Сделка:**

- `wordpress_class`: `11`
- `Какой курс куплен`: `Стандарт`
- `Какой предмет выбрал`: `Русский`, `Биология (Геля)`

**3. Счет:**

- **Комментарий**: `https://egeland.amocrm.ru/leads/detail/40095211`
- **Позиции:**
   1. Название: `Весенний курс 2к26 ЕГЭ 11 класс`, Цена: 3000, Количество: 1
  2. Название: `Весенний курс 2к26 ЕГЭ 11 класс`, Цена: 3000, Количество: 1
